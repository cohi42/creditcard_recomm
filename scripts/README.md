# scripts

이 폴더는 본 파이프라인의 주 실행 경로가 아니라, 연구 중간에 DB 상태를 빠르게 확인하기 위한 보조 스크립트를 담습니다. 평가 수치나 데모 결과를 직접 생성하는 폴더는 아니지만, 정형화 방식이 바뀔 때 가정이 실제 DB에 반영되었는지 확인하는 데 사용했습니다.

## Input / Output

| 구분 | 내용 |
| --- | --- |
| Input | `db/cards.db` 또는 정형화 후 생성된 SQLite view |
| Output | 콘솔에 출력되는 샘플 카드/혜택/유의사항 점검 결과 |

## 파일

| 파일 | 역할 |
| --- | --- |
| `sample_card.py` | 평가 대상 카드의 카페 혜택과 유의사항 결합 view가 제대로 만들어졌는지 샘플로 확인합니다. |
| `search_baseline.py` | 전월 실적 표현이 없는 카페 혜택을 찾아 baseline/정형화 입력 차이를 점검합니다. |
