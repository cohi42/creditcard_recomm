# persona_image

이 폴더는 Streamlit 데모 viewer에서 6개 소비 페르소나를 구분하기 위해 사용하는 이미지 자산을 담습니다. 추천 모델의 입력이나 평가 정답에는 영향을 주지 않으며, 전시 시연에서 소비 패턴을 빠르게 식별하도록 돕는 표현 자산입니다.

| 파일 | 연결되는 페르소나 |
| --- | --- |
| `P1.png` | 스타벅스 다빈도형 |
| `P2.png` | 스타벅스 가끔형 |
| `P3.png` | 이디야 생활권형 |
| `P4.png` | 프리미엄 카페 모임형 |
| `P5.png` | 주요 프리미엄 체인 순회형 |
| `P6.png` | 저가커피 초저가 다빈도형 |

이미지 파일명은 `app.py`에서 `persona_id`와 직접 매칭됩니다. 새 페르소나를 추가할 경우 `persona_transactions.json`, 추천 결과 JSON, 이 이미지 파일의 번호 체계를 함께 맞춰야 합니다.
