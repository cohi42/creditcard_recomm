# card_crawling

이 폴더는 연구의 출발점인 카드 원천 데이터를 확보하는 수집 파이프라인입니다. 본 프로젝트는 특정 카드사나 소수 샘플이 아니라 충분히 큰 원천 데이터가 필요했습니다.

## Input / Output

| 구분 | 내용 |
| --- | --- |
| Input | 카드고릴라 내부 API `https://api.card-gorilla.com:8080/v1/cards/{id}` |
| Output | `data/raw/{id}.json` 원천 카드 JSON 2,790건, 수집 통계 |

`main.py`는 카드고릴라 내부 API의 순차 ID를 탐색해 카드 JSON을 저장합니다. 탐색 범위는 1~3000이고, 수집 결과 2,790장의 카드 데이터를 확보했습니다. 요청 실패와 이미 저장된 파일을 구분해 이어받을 수 있게 만든 이유는, 크롤링 자체보다 이후 정형화 실험의 입력을 안정적으로 고정하는 것이 중요했기 때문입니다.

`validate.py`는 수집 직후의 품질 확인용 스크립트입니다. 카드 유형, 노출 여부, 단종 여부, 카드사 분포, 혜택 카테고리 분포를 집계해 수집 데이터가 연구 범위로 쓸 수 있는지 확인합니다. 여기서 카페 혜택 보유 카드 463장이 파일럿 범위로 선택되었습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `main.py` | 카드고릴라 API를 순회하며 raw JSON을 저장합니다. |
| `validate.py` | 수집 결과의 기본 통계와 카테고리 분포를 점검합니다. |
| `data/README.md` | raw JSON의 주요 필드와 수집 통계를 설명합니다. |

`data/raw/`와 `logs/`는 `.gitignore` 대상입니다. GitHub에는 원천 JSON을 직접 올리기보다, 어떤 데이터를 어떤 구조로 수집했는지 설명하는 문서만 남깁니다.

```bash
cd card_crawling
python main.py
python validate.py
```
