# Card Gorilla Raw Data Dictionary

이 문서는 Git에 올리지 않는 `data/raw/` 원천 JSON의 구조를 설명합니다. 원천 파일은 크고 재수집 가능한 자료라 `.gitignore` 대상이지만, 어떤 필드가 이후 정형화와 추천 판단의 근거가 되었는지는 저장소 안에 남겨 두기 위해 작성했습니다.

- API 엔드포인트: `https://api.card-gorilla.com:8080/v1/cards/{id}`
- 수집 일자: `2026-03-12`
- 탐색 ID 범위: `1~3000`
- 저장 경로: `data/raw/{id}.json`
- 총 수집 건수: `2,790`

## 연구에서 중요한 필드

| 필드 | 쓰임 |
| --- | --- |
| `idx` | DB의 `card_id`로 사용되는 카드고릴라 내부 ID입니다. |
| `name`, `corp.name` | 추천 결과에서 카드명과 카드사를 식별하는 기본 정보입니다. |
| `cate`, `c_type` | 신용/체크 등 카드 기본 분류를 확인합니다. |
| `annual_fee_basic`, `pre_month_money` | 카드 기본 조건과 전월 실적 맥락을 보조합니다. |
| `card_img.url`, `corp.logo_img.url` | viewer에서 카드와 카드사를 보여줄 때 사용할 수 있는 이미지 정보입니다. |
| `top_benefit` | 카드의 요약 혜택을 빠르게 파악하는 참고 정보입니다. |
| `key_benefit` | 정형화의 핵심 입력입니다. 각 혜택의 `info`에는 HTML 형태의 비정형 약관 텍스트가 들어 있습니다. |
| `search_benefit` | 카페, 쇼핑, 주유 등 파일럿 카테고리 후보를 고르는 데 사용한 카테고리 태그입니다. |
| `is_visible`, `is_discon` | 실제 서비스 노출/단종 여부를 확인하는 품질 점검 필드입니다. |

## 수집 데이터 기본 통계

| 항목 | 값 |
| --- | ---: |
| 탐색 범위 | 1~3000 |
| 수집 카드 수 | 2,790 |
| 신용카드 추정(`CRD`) | 2,112 |
| 체크카드 추정(`CHK`) | 678 |

카드사 분포는 롯데카드 545건, 삼성카드 370건, KB국민카드 284건, 우리카드 276건, 신한카드 246건 순으로 나타났습니다. 이 분포는 특정 카드사 한 곳의 약관 표현에 과적합하지 않도록, 이후 표본 관찰과 평가 카드 선정에서 카드사를 분산시키는 근거가 되었습니다.
